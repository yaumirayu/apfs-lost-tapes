# Фактические проверки — 9 ноября 2026

## Исправленная локальная копия

- Все 12 ZIP прочитаны автоматически с проверкой CRC при извлечении; оригиналы сохранены.
- 88 MP3, 6 релизов, точное совпадение путей с каталогом HTML.
- SHA-256 каждого файла совпадает с содержимым исходного ZIP.
- Файл-заглушка `assets/audio` заменён папкой.
- Отдельный релиз «Слепые» исключён, запись оставлена в «Опианариуме».
- Браузер Chromium: каждый из 88 MP3 воспроизводился с продвижением таймера,
  перематывался в середину, полностью декодирован через OfflineAudioContext;
  подтверждён ненулевой звуковой сигнал. Это не прослушивание всех композиций от начала до конца.
- Прошли: пауза/продолжение, следующий/предыдущий, перемотка ползунком,
  громкость, mute/unmute, shuffle, повтор одного, всех и отключение повтора.
- Поиск «Слепые» возвращает одну запись; переключение избранного работает.
- Все изображения в DOM загрузились с ненулевыми размерами.
- Ширины iframe 390, 768, 1440 px: горизонтального переполнения нет.
  Физические iPhone/Android не проверялись.
- Оформление и анимация кассеты сохранены. Анимированные полосы работают без
  подключения MediaElementSource, чтобы воспроизведение не зависело от Web Audio.
- Клавиатурные команды больше не перехватывают штатное нажатие кнопок.
- ZIP/BAT исключены; Git LFS отсутствует; максимальный MP3 12 016 209 байт.

Подробные результаты: `browser-checks.json`, контрольные суммы: `audio-manifest.json`.
