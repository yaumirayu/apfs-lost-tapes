# АПФС — LOST TAPES.exe

Музыкальный архив «Автостопом по фазе сна»: 6 релизов, 88 MP3.
Оформление Windows 98 / VHS / CRT и анимация кассеты сохранены.

## Структура

- `index.html` — интерфейс, каталог и встроенные обложки.
- `assets/audio/` — 88 файлов с именами, совпадающими с каталогом.
- `audio-manifest.json` — исходный архив, размер и SHA-256 каждого MP3.
- `validate.py` — повторяемая проверка целостности: `python validate.py`.
- `CHECKS.md` и `browser-checks.json` — фактические результаты проверки.

ZIP и BAT не входят в репозиторий. Git LFS не используется.
Общий размер аудио: 571 612 144 байта; максимальный файл: 12 016 209 байт.

## Локальный запуск

В этой папке выполнить `python -m http.server 8000`, открыть http://localhost:8000/.
Для перемотки до окончания загрузки нужен HTTP-сервер с поддержкой Range;
GitHub Pages поддерживает запросы диапазонов.

## Публикация

Опубликовано и проверено: https://yaumirayu.github.io/apfs-lost-tapes/
88/88 публичных MP3 прошли воспроизведение, перемотку и проверку SHA-256.

Публиковать MP3 только после подтверждения владельцем права на распространение.
GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
После разрешения и при настроенной авторизации: `git push origin main`.
Проверять опубликованные MP3 отдельно: локальная проверка не подтверждает загрузку на Pages.

Пробел — воспроизведение/пауза, стрелки — ±5 секунд, M — звук, S — перемешивание.
На кнопках и полях сохраняется штатное поведение клавиатуры.
